# 美術清單：劇情背景與章節地圖（ART-002）

> 由 Claude Code 依劇本整理（2026-10-05）。製作規格見 [TASKS.md](../TASKS.md)「交付規格 C」。
> 程式對照表：`src/content/backgrounds.ts`（劇本 bg id → 圖檔＋色調）。同一地點的日夜、明暗由畫面疊色調，**一個地點只畫一張白天（或該地點本來的光線）版本**。
> 優先順序：序章、第一章先做（試玩最先看到），之後依章節往下。

共通要求：B 國風厚塗、1920×1080、**不要人物**（立繪會疊上去）、不要文字；畫面下方 1/3 細節少一點（對話框）。PAL1 DOS 版有對應場景的，先找原作畫面參照構圖與配色。
