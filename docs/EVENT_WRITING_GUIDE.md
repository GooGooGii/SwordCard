# 奇遇文本寫作守則（Event Writing Guide）

> 2026-06-11 立。目的：把奇遇從「機制及格」寫到「文字有魂」——PAL1 / 仙俠文字冒險的風情。
> 適用：`scripts/event_data.gd` 全部 34 個 variant 的 tree 文本與 character_flavors。
> 新增 / 改寫事件**必須**照本守則；smoke test 守結構，本檔守語感。

## 一、診斷：舊文本的四種病

| 病 | 例（舊） | 為什麼死板 |
|---|---|---|
| Prompt 是鏡頭說明，不是處境 | 「山壁後一眼清泉，水氣溫潤。你蹲下身——」 | 交代了佈景，沒有誘惑、不安或懸念；玩家沒有「身在其中」 |
| Log 是結算說明書 | 「玉入手心，溫潤微熱。」 | 沒有動作回放、沒有餘韻，像系統訊息 |
| Label 是按鈕，不是抉擇 | 「離去」「取玉」 | 沒有態度；玩家讀不出這個選擇「像誰會做的事」 |
| Node 不承接因果 | 上一步「入水沐浴」→ 下一步 prompt 直接「水底有什麼在動」 | 跳過了玩家動作的直接後果，斷了敘事的呼吸 |

## 二、硬規則（改文本時逐條對照）

1. **root prompt**：2–3 句、60–110 字。
   句 1＝感官開場（聲／光／氣味／觸感擇一）；句 2＝發現或異常；句 3＝把張力放出來（誘惑、或不對勁）。
   ❌ 禁用「你看到 X。要怎麼做？」句式。
2. **character_flavors**：每角色 80–140 字、該角色的視角＋一段私人記憶。聲口見 §三。
   已寫得好的（spring 等 6 個原凍結事件）不要動。
3. **node prompt**（子節點）：40–80 字。**第一句必須是玩家剛才那個選擇的直接後果**（因果感），再給新細節與新壓力。
4. **choice label**：動詞開頭、帶態度，6–14 字。危險選項的措辭要「聞得到危險」
   （「把整隻手探進符匣」優於「拿取符紙」）；謹慎選項要讀得出克制。**不可劇透數值。**
5. **outcome log**：2–3 句、40–90 字。順序＝動作回放 → 感官餘韻 →（必要時）一句自然語暗示機制後果。
   數字交給 UI 浮字顯示，敘事裡**不寫數字**。失敗 log 寫「世界的反作用力」，不嘲諷玩家。
6. **PAL1 錨點**：每事件至少 1 個正史細節（十里坡、餘杭客棧、仙靈島水月宮、林家堡、蘇州、
   將軍塚、鎖妖塔、苗疆蠱毒、拜月教……查 `docs/PAL1_CANON.md`）。自然帶過，不硬塞。
7. **禁則**：敘事中不出現遊戲術語（護體／靈力／抽牌——log 末句的機制暗示用自然語：
   「下一場交手，你的氣會更長」）；不用 emoji；繁體中文；
   **不改 id / effects / requires / gamble 數值 / 樹結構**；title 可微調但勿大改。

## 三、四角色聲口表（character_flavors / 角色限定選項用）

| 角色 | 視角慣性 | 記憶錨點 | 語感 | 一句試金石 |
|---|---|---|---|---|
| 李逍遙 | 先動手再想，嘴上不正經、心裡有桿秤 | 餘杭十里坡、外婆、客棧雜活、酒劍仙的醉拳劍 | 口語、市井機靈、偶爾冒出一句沒大沒小的比喻 | 「這要是讓外婆知道，又得揪耳朵。」 |
| 趙靈兒 | 先感受靈氣再看人，溫柔但藏著身世的孤獨 | 仙靈島、水月宮、姥姥、女媧血脈 | 輕、靜、句子收得柔；對萬物有憐惜 | 「水也是有心事的，只是說得慢。」 |
| 林月如 | 先評估威脅，嘴硬心軟，輸贏看得重 | 林家堡、父親林天南（南武林盟主）、比武招親 | 短句、利落、偶爾彆扭的關心 | 「哼，本姑娘才不是擔心你。」 |
| 阿奴 | 用蠱與直覺理解世界，生死觀輕盈 | 苗疆、蠱蟲、白苗祭典、山林 | 跳躍、天真但一針見血；對毒物如對朋友 | 「牠不壞，牠只是餓了。」 |

## 四、範本（spring 改寫前後對照）

**root prompt 舊**：「山壁後一眼清泉，水氣溫潤。你蹲下身——」（19 字）
**root prompt 新**：「水聲是先到的，隔著一面山壁，淙淙地敲。繞過去，一眼清泉嵌在石窩裡，
水面平得像一塊未琢的鏡，倒映著你風塵僕僕的臉。水氣溫潤撲面，喉頭忽然發緊——
這一路，你已經很久沒有喝過一口乾淨的水了。」

**log 舊**：「玉入手心，溫潤微熱。」
**log 新**：「指尖破開水面，涼意直竄手肘。那塊玉像是等了很久，輕輕一托便離了泉底，
入掌溫潤微熱，彷彿還帶著誰的體溫。水面合攏，倒影裡你的身後，似乎有什麼悄悄退開了。」

## 五、流程

1. 改完一批 → `godot --headless --path . -s scripts/smoke_test.gd`（樹結構測試把關）。
2. `render_event.gd` 抽 1–2 個事件實機截圖，確認長文不破版（單欄可捲動版面已支援）。
3. commit message 用 `feat(events): 文本重寫 — <事件清單>`。
