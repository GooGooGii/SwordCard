# 流派設計（STS 式，依仙劍一原作招式）

2026-10-08。使用者要求：參考殺戮尖塔做出「不同流派、不同手感」，並且**流派必須從原作角色招式分出來**。
招式資料來源：百度百科各角色條目的「法術技能」表（初代 DOS／98 版；標註「新仙劍新增」者不採用）。

原則：
- 每位主角兩條流派，各有最強與最弱的場景（設計支柱 2：四角色＝四種解法）。
- 牌名優先使用原作招式名；原作沒有的才自創，並在 canon 欄註明「本作」。
- 流派靠「心法」（常駐觸發）成形，靠稀有度與獎勵機率引導玩家收集。

## 無主牌（殺戮尖塔的「無色牌」）

使用者指出無主牌本身就是一個分類（2026-10-08）。定位照殺戮尖塔：**不屬於任何流派的萬用工具牌**，單張強度高、但不疊流派，
由當下 HP 最高的清醒隊員出手；**不出現在一般戰後三選一**，主要從客棧購買、奇遇、精英與頭目獎勵取得。

| 來源 | 牌（原作依據） | 定位 |
|---|---|---|
| 多人共有的原作招式 | 元靈歸心術（逍遙、月如、阿奴都會）、凝神歸元、氣療術、冰心訣（逍遙、靈兒）、金剛咒、真元護體 | 補血、解除異常、護體 |
| 天書與秘笈 | 酒劍仙所傳、蜀山劍譜一類的過牌、找牌、升級 | 牌組運轉（殺戮尖塔的「師父的指點」「啟示」） |
| 符咒雜項 | 天師符、定身符、驅魔香（本作） | 控場、應急 |

另外兩個相關分類：
- **心念**：主人昏迷時，他的牌暫時變成「心念」（已實作）。
- **狀態牌／詛咒牌**（殺戮尖塔的傷口、暈眩、詛咒）：敵人招式會塞進牌組，例如毒娘子「纏魂絲」塞「纏絲」（不能打、回合結束扣血）、
  三屍咒塞「屍毒」。讓敵人的威脅不只是扣血；靈兒淨化、阿奴靈血咒可以移除。

## 卡牌升級（使用者要求，2026-10-08）

現況：87 張一般牌都有升級版（`upgrade` 欄位），客棧可**無限次花錢升級**，而且休息**免費補滿全隊**——沒有取捨。
改成殺戮尖塔的做法：

1. **客棧「歇腳」二選一**（殺戮尖塔的營火）：
   - 休息：全隊回復最大生命的 30%；
   - 練功：免費升級一張牌（仙劍味：在客棧後院練成新招）。
   - 客棧的「掌櫃的貨」照舊可買牌、刪牌，另加藥品與法寶；**不再賣升級**。
2. **其他升級來源**：精英、頭目獎勵偶爾給「已升級」的牌；奇遇（例如酒劍仙指點）；無主牌「秘笈」類可在戰鬥中升級。
3. **升級不只是數字變大**（殺戮尖塔的好升級會改變用法）：降費、移除消耗、加保留、多一段、從單體變全體，
   對流派關鍵牌尤其如此（例如斬龍訣升級後不必蓄滿指勁）。
4. **介面**：升級過的牌名加「＋」、牌框加光；練功時並排顯示「升級前 → 升級後」。

## 實作順序

1. 共用機制（已完成）：控制狀態、心法觸發、法寶觸發、藥品欄。
2. 流派需要的新效果：指勁層數、花銅錢、引爆中毒、斬殺、收妖煉藥、變身。
3. 依上表改寫與新增卡牌（每流派約 8～12 張），補心法與法寶。
4. 獎勵機率依流派與稀有度；客棧賣藥與法寶。
5. 依流派分別跑 bot 平衡。
