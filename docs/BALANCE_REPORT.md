## 二、診斷

**縱向（難度曲線）健康**：開場易、升級有感、終盤 boss 有壓力。

**橫向（角色間）失衡**：四角色強度差距過大，最明顯在「起始牌組 vs 蜈蚣大王」(13% vs 87%) 與「Lv20 拜月教主」(50/53% vs 87/93%)。

**根因**：10 回合時限對高血 boss 偏好「持續輸出 / AOE / 中毒 engine」型角色：
- **阿奴**：起手蠱毒 engine，對高 HP boss 滾雪球，時限內穩定碾過。
- **林月如**：續航+反擊，撐得住時限。
- **李逍遙 / 趙靈兒**：單體直傷型，沒有續航機制，被回合時限卡死。

李逍遙作為主角，輸出曲線卻是四角最弱之一（起始 13%、Lv10 87% 皆墊底段位）。

## 三、建議（暫不執行，待決策）

1. **buff 弱角（低風險）**：給李逍遙 / 趙靈兒起始牌組加一點對高血 boss 的續航或爆發手段，把 13%/30% 往中間（~40-50%）拉，不動阿奴/林。
2. **全面重調**：系統性拉近四角起始勝率，重跑後改寫 `BALANCE_BASELINES_MID`。改動較大。

> 容差說明：smoke test `BALANCE_TOLERANCE_PP = 15`，是給隨機 AI 的雜訊空間，不是平衡緩衝。本報告數字為固定 seed 下的觀測值。

## 四、AI 平衡驅動器（agent 親自玩）

隨機 AI 出牌會把橫向差距測歪——它從不換人、不指定目標、不打 combo、不規劃牌組／獎勵。
為取得「會玩的人」的真實平衡，已建置 **AI 平衡驅動器**（見 [`docs/AI_BALANCE_HARNESS.md`](AI_BALANCE_HARNESS.md)）：
headless 跑一整個 run，在每個決策點（加護／地圖／戰鬥／獎勵／商店／奇遇／休息）停下交由 agent 決定，
**戰鬥用真實 BattleController**。

- 引擎 `scripts/ai_run_engine.gd`、串口 `tools/ai_run.gd`、防鏽測試 `_test_ai_run_engine_smoke`。
- 既有隨機 AI regression 保留為 CI 防回歸；本驅動器是按需質性工具。

### 初步實測觀察（李逍遙，act 1 起手，agent 操刀）

實際手玩第一場（vs 小偷 62 HP）即印證報告推論：

1. **傷害輸出靠抽牌運**：某回合手上 5 張只有 1 張攻擊牌，輸出被迫中斷——這正是「單體直傷型在時限下被卡」的微觀成因。
2. **但技巧可緩解**：戰鬥後三選一出現 `逍遙遊`(0耗抽1+回靈力) 與 `真元凝聚`(抽2+回血) 等**過牌**卡。
   會玩的人優先拿過牌來修補抽牌一致性——隨機 AI 則是隨機亂拿。
   → 推測「會玩」的李逍遙真實勝率應顯著高於隨機 AI 的 13%／30%；橫向差距也應收斂。

> 完整多角色／多場 run 的 agent 實測勝率**尚未跑完**（一整個 8 幕 run ≈ 500 個決策點，
> 由 agent 逐回合手玩成本高）。待與使用者確認實測範圍（哪些角色、幾場、是否整 8 幕 vs 只測爭議中段 boss）後補上。

## 五、全 run 自動跑分（AiRunEngine 改良 policy，確定性）

> 資料來源：`tools/ai_batch.gd` 單進程批次，用 `AiRunEngine.auto_choice` 改良啟發式 policy
> 跑完整 8 幕 run（真實 BattleController）。**已修正關鍵 bug**：`setup()` 原本在地圖生成後
> 呼叫 `randomize()`，導致戰鬥/抽牌走非確定性 RNG，量測無法重現；現移除，**同 seed 完全可重現**。

### 16 seeds × 4 角色（solo，A0）通關率

| 角色 | 通關率 | 平均抵達幕（/8） | 目標牌組 |
|---|---|---|---|
| 李逍遙 | **87.5%** | 7.31 | 17 |
| 林月如 | **87.5%** | 7.25 | 26 |
| 趙靈兒 | 68.8% | 6.19 | 18 |
| 阿奴 | 25.0% | 3.69 | 23 |
| 整體 | **67.2%** | — | |

> 上表為最新（含 policy 六次修正：①出毒引爆時機 ②per-character 目標牌組 ③會用治療牌
> ④會用藥品 ⑤多段攻擊傷害正確計算 ⑥錢多優先走商店買遺物）。
> 各版本整體勝率：32.8% → 40.6% → 56.3% → 56.3% → 62.5%（+多段修正）→ **67.2%（+商店路線）**。
> ⑤多段 bug 修正讓李逍遙 56.3%→87.5%；⑥「錢多走商店買光遺物」讓活得久的林月如
> 75%→87.5%、趙靈兒 62.5%→68.8%（遺物滾雪球）。
> 註：阿奴在 ④⑤⑥ 皆不變（25%）——她多半第 3 幕前死於雜兵消耗，根本來不及變有錢/發揮多敵 AOE；
> 她的瓶頸是「脆弱早死 + combo 需規劃」，是啟發式測不到、得靠互動 agent 的天花板。

### 解讀

- **排名：李逍遙 ≈ 林月如 > 趙靈兒 > 阿奴。** 多段傷害修正後李逍遙（連擊速攻）與林月如（續航+買遺物）
  並列最強；阿奴仍墊底但已從 6%→25%。
- **阿奴 25.0% 仍部分受 policy 限制**：毒流是 setup-payoff，啟發式雖已會「疊毒 ramp→留爆點→斬殺才引爆→
  低血回血」，仍不如真人精算毒節奏與用藥。真實上限要靠互動 agent；但「墊底」這個**相對排名**可信。
- 與第一節「act1 100% 勝率」一致：開場不勸退；難度在中後段（第 2 幕起）才咬人。

> 治療牌 policy（會玩的人習慣，使用者口述）：低血量（<50%）主動打靈血咒續命；
> 穩贏的最後一回合（最後一隻、可斬殺、回血後仍打得死）先回血再補刀，把 HP 帶進下一場。
>
> 藥品 policy：戰鬥中——boss 戰才用珍貴進攻藥（力量藥趁早、破綻藥在 focus 未破綻時，放大整場輸出）、
> 能量耗盡但手牌有牌時用靈力藥、手牌將盡用抽牌藥；危急（<25%）用補血藥。
> 商店——血量 <60% 先買一瓶補血藥備用（生存優先於擴牌）。進攻藥不浪費在雜兵。

### policy 改良摘要（`AiRunEngine.auto_choice` / `_auto_battle`）

戰鬥：取代原本「打第一張負擔得起的牌」的笨 policy，逐動作評估——
**引爆只在可斬殺 / 毒層過高才出**（避免清空 DoT 引擎，是阿奴從 6.3%→18.8% 的關鍵）→
致命先殺威脅源或補血/疊滿格擋 → 集火可殺即殺 → 重擊先擋 → 發展型能力（力量/毒引擎/抽牌）早放 →
阿奴疊毒 → 最大傷害攻擊 → 保底格擋/出牌。

選牌（meta）：模型化「真玩家心中有目標牌組 + 總量限制」——**per-character 目標牌組張數**
（速攻精簡 / 引擎續航偏厚，達標即略過獎勵），未達標則無偏隨機取一張。
> 註：曾試「挑稀有」「挑便宜攻擊」皆比隨機選**更差**（32.8%→17–20%）——好的選牌需 per-character
> win-con 判斷，是啟發式做不到、得靠互動 agent 的事；故 reward option 改附 `rarity/card_type/cost`
> 結構化欄位供 agent 評估，啟發式本身只做「規模紀律」不做「品質挑選」。

其餘 meta：地圖——血<30% 繞休息、錢≥150 優先走商店（把遺物買光，會玩的人習慣）；
加護偏好精簡/學招；商店——優先逐件買光遺物（純增益不肥牌）、其次血<60% 補血藥、再其次擴牌。
