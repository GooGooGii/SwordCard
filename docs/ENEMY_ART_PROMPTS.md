# Enemy Art Prompts

最後更新：2026-06-09

用途：整理目前仍缺專屬肖像的敵人產圖 prompt，供 Codex / Gemini / 委外美術直接使用。

共通規格：

- 路徑：`assets/art/enemies/<id>.png`
- 畫面：單體敵人肖像、去背或近透明背景、可直接放進戰鬥 UI
- 風格：PAL1 正史優先，水墨國風，乾淨插畫，不要歐美奇幻盔甲，不要 Q 版，不要現代服飾
- 構圖：角色置中偏上，保留四周安全裁切空間，避免武器或肢體貼邊
- 光影：清楚輪廓、中高對比，縮到遊戲尺寸後仍看得出五官與主輪廓
- 輸出：PNG，直式構圖，建議 768x768 或更高
